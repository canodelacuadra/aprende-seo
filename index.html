Recorrido

Las tres actividades

Cada actividad continúa el mismo proyecto ficticio: TecnoSerprofes, una empresa de reparación y mantenimiento informático en Toledo. No son ejercicios aislados: lo que haces en una actividad se reutiliza en la siguiente.

01

SEO básico en una página estática

Crea una web de tres páginas con HTML semántico, configura títulos, metas, canonical, URLs amigables, robots.txt, sitemap, 404 y Open Graph, y publícala en GitHub Pages con Search Console.

Disponible 4-6 h HTML + CSS
Abrir actividad
02

SEO avanzado en una página estática

Amplía la web con un blog, datos estructurados, Core Web Vitals, imágenes optimizadas, hreflang, clústeres de contenido y una auditoría técnica con Screaming Frog.

Disponible 4-6 h SEO técnico
Abrir actividad
03

SEO en WordPress y WooCommerce

Configura WordPress con Yoast, organiza taxonomías, controla duplicados y paginación, y optimiza una tienda WooCommerce: fichas, variaciones, filtros, reseñas, checkout y rendimiento.

Disponible 5-7 h CMS + tienda
Abrir actividad

Método de trabajo

Así está pensada cada actividad

No es un tutorial para copiar y pegar: cada paso incluye una comprobación, una evidencia que debes guardar y una conexión con las preguntas del test de autoevaluación.

  1. Lee el objetivo Antes de tocar código, entiende qué vas a conseguir y por qué importa para el SEO.
  2. Haz el paso Cada paso tiene instrucciones, código de ejemplo y una explicación de las decisiones.
  3. Comprueba Usa el navegador, DevTools, Search Console o Lighthouse para verificar el resultado.
  4. Guarda la evidencia Captura, informe o URL publicada. Al final se entrega junto con la checklist.

Antes de empezar

Lo que necesitas

Editor y servidor local

Visual Studio Code y la extensión Live Server para probar las URLs limpias y las rutas relativas sin subir nada a GitHub.

Cuenta de GitHub

Para publicar la web con GitHub Pages y comprobar después el rastreo y la indexación con Google Search Console.

Navegador y herramientas

Chrome, Edge o Firefox con DevTools. Para la actividad 1 también necesitarás una imagen con licencia y, si quieres, PageSpeed Insights.
